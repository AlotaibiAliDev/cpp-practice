# C++ Beginner Projects

This repository contains simple C++ programs that I built while learning programming. The goal is to practice basic concepts such as conditions (if statements).

---

## Included Programs

### 1. Calculator

A simple calculator that performs:

* Addition
* Subtraction
* Multiplication
* Division

just between two numbers.
---

### 2. Grade System

A program that assigns a grade based on the score:

* A
* B
* C
* D
* F

---

### 3. Max Number

A program that finds the largest number among user inputs.

---

### 3. Even or Odd

A program that checks whether a number is even or odd based on user input.

---

## How to Run

1. Make sure you have a C++ compiler (like g++)
2. Compile and run the program.
